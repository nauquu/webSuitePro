# Web Suite Pro ⚡

Mở rộng trình duyệt đa năng: Ẩn Quảng Cáo/Gợi ý Facebook, Chặn UID, Giải Captcha tự động (Buster Engine) và YouTube NonStop.

## 🌟 Chức năng chính

1. **Chặn Quảng Cáo Facebook (FB Ad Blocker)**:
   - Tự động ẩn bài viết nhãn "Ad", "Sponsored", "Được tài trợ", "Quảng cáo".
   - Bóc tách mã hóa thẻ span rác (obfuscated dummy spans) và thuộc tính CSS flexbox order.
   - Chặn zero-flicker ngay tại thời điểm render DOM.

2. **Ẩn bài viết Gợi ý rác (Page & Group Hider)**:
   - **Ẩn Page chưa Follow**: Tự động ẩn bài viết từ Page chưa theo dõi ("Follow", "Theo dõi", "Suggested for you").
   - **Ẩn Group chưa Join**: Tự động ẩn bài viết từ Group chưa tham gia ("Join", "Tham gia", "Suggested group").

3. **Chặn bài viết theo UID/Username (Blacklist)**:
   - Nút bấm thêm nhanh UID trực tiếp trên **Wall/Trang cá nhân**.
   - Mục **Ẩn mọi bài từ tác giả này** tích hợp trong Menu 3 chấm (`...`) của từng bài viết.
   - Giao diện Popup quản lý danh sách đen linh hoạt.

4. **Tự động giải Captcha (Buster Engine)**:
   - Tự động phát hiện reCAPTCHA v2, hCaptcha và Facebook Security Captcha.
   - Tự chuyển sang thử thách Âm thanh (Audio Challenge), bóc file audio và nhận dạng giọng nói thành văn bản để vượt Captcha.

5. **YouTube NonStop**:
   - Tự động phát tiếp khi YouTube hiện thông báo *"Video đã tạm dừng. Bạn có muốn tiếp tục xem?"*.
   - Tự động bỏ tạm dừng video để phát liên tục.

## 🚀 Cài đặt

1. Tải repository này về máy hoặc clone qua Git.
2. Mở trình duyệt Chrome/Edge và truy cập `chrome://extensions`.
3. Bật **Developer mode (Chế độ dành cho nhà phát triển)** ở góc trên bên phải.
4. Bấm **Load unpacked (Tải tiện ích đã giải nén)** và chọn thư mục project này.
